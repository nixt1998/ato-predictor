## 📐 设计稿结构

本设计稿包含以下页面：

1. **首页（Landing Page）** - 欢迎页面，门户入口
2. **计算界面（Prediction Tool）** - 核心功能，风险计算
3. **数据上传（Data Upload）** - 研究数据上传
4. **关于页面（About）** - 项目介绍
5. **算法页面（Algorithm）** - 模型说明
6. **隐私政策（Privacy Policy）** - 隐私声明
7. **免责声明（Disclaimer）** - 法律声明
8. **联系我们（Contact Us）** - 联系方式

**设备尺寸：**
- Desktop: 1920x1080（主要）
- Laptop: 1366x768（次要）

## 🎬 动画效果详细说明

### 页面加载动画

```
初始状态: 透明度 0，向下偏移 20px
动画: 淡入 + 向上滑动
Duration: 0.6s
Easing: ease-out
```

### 按钮悬停动画

```javascript
// Framer Motion 配置
<motion.button
  whileHover={{ 
    scale: 1.05,
    y: -2,
    boxShadow: '0 8px 20px rgba(0, 94, 184, 0.4)'
  }}
  whileTap={{ scale: 0.98 }}
  transition={{ duration: 0.2 }}
>
  开始计算
</motion.button>
```

### Tab 切换动画

```javascript
// 内容淡入淡出
<AnimatePresence mode="wait">
  <motion.div
    key={activeTab}
    initial={{ opacity: 0, x: 20 }}
    animate={{ opacity: 1, x: 0 }}
    exit={{ opacity: 0, x: -20 }}
    transition={{ duration: 0.3 }}
  >
    {content}
  </motion.div>
</AnimatePresence>
```

### 卡片悬停动画

```css
.card {
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.card:hover {
  transform: translateY(-8px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);
}
```

### 计算完成提示动画

```javascript
// Toast 入场
initial={{ x: 400, opacity: 0 }}
animate={{ x: 0, opacity: 1 }}
exit={{ opacity: 0 }}
transition={{ 
  type: 'spring',
  stiffness: 500,
  damping: 40
}}
```
