# 🎨 Nano Banana Pro 绘制指南

**工具**: Nano Banana Pro  
**目标**: 绘制 ATO CardiTox Logo  
**预计时间**: 30-60 分钟

---

## 🚀 快速开始（5步）

### 第 1 步: 新建项目（2分钟）

打开 Nano Banana Pro:
```
文件 > 新建
画布大小: 1024 × 1024 px
背景: 透明
色彩模式: RGB
单位: Pixels
```

---

### 第 2 步: 设置色板（3分钟）

添加以下 5 个颜色到色板：

| 颜色名称 | HEX 代码 | 用途 |
|---------|---------|------|
| Medical Blue | `#005EB8` | 盾形顶部、主要元素 |
| Tech Blue | `#0077B6` | 渐变过渡 |
| Teal | `#00A896` | 渐变中段 |
| Life Green | `#10B981` | 盾形底部、曲线 |
| White | `#FFFFFF` | 线条勾勒 |

**操作**:
1. 打开色板管理器
2. 点击"添加颜色"
3. 输入 HEX 代码
4. 命名并保存

---

### 第 3 步: 设置网格（可选，1分钟）

```
视图 > 显示网格
网格大小: 64px (16×16 网格)
细分: 8 (每格 8px 小格)
吸附到网格: 开启
```

这样可以更精确地对齐元素。

---

### 第 4 步: 绘制 Logo（30-45分钟）

#### 推荐方案: A1 - 守护之盾

**元素 1: 盾形外轮廓**（10分钟）

1. **选择工具**: 钢笔工具 (P)
2. **绘制路径**:
   - 顶部尖角: 坐标 (512, 87)
   - 左上角: (162, 287)
   - 左下角: (162, 687)
   - 底部圆弧: 使用贝塞尔曲线连接
   - 右侧对称绘制
3. **应用渐变**:
   - 类型: 线性渐变
   - 角度: 180° (垂直)
   - 色标 1: `#005EB8` at 0%
   - 色标 2: `#0077B6` at 35%
   - 色标 3: `#00A896` at 65%
   - 色标 4: `#10B981` at 100%
4. **线条设置**:
   - Line Cap: Round（圆角端点）
   - Line Join: Round（圆角连接）

---

**元素 2: 心形中心**（15分钟）

1. **选择工具**: 钢笔工具或形状工具
2. **绘制方式**:
   - **方式 A**: 两个圆 + 一个三角形组合
     - 上部: 两个圆形 (半径 80px)，圆心位置 (412, 450) 和 (612, 450)
     - 下部: 三角形，三个顶点 (332, 470) / (512, 630) / (692, 470)
     - 合并形状: Pathfinder > Union
   
   - **方式 B**: 直接用钢笔工具绘制心形轮廓
     - 顶部左弧: 从 (332, 470) 开始
     - 顶部右弧: 到 (692, 470)
     - 底部尖角: (512, 630)
     - 闭合路径

3. **样式设置**:
   - 填充: 无
   - 描边: `#FFFFFF` (白色)
   - 描边宽度: 8px
   - Line Cap: Round

4. **位置**: 
   - 水平居中于盾形
   - 垂直位置: 盾形中心偏上 50px

---

**元素 3: 预测曲线**（10分钟）

1. **选择工具**: 钢笔工具 (P)
2. **绘制路径**:
   - 起点: 心形底部尖端 (512, 630)
   - 使用贝塞尔曲线绘制平滑上升路径
   - 方向: 向右上延伸约 150px
   - 控制点: 调整为平滑的 S 型曲线

3. **样式设置**:
   - 填充: 无
   - 描边: `#10B981` (亮绿)
   - 描边宽度: 6px
   - Line Cap: Round

4. **可选装饰**: 
   - 在曲线上添加 2-3 个小圆点
   - 圆点直径: 12px
   - 填充: `#10B981`

## 🎨 渐变设置详解

### Nano Banana Pro 渐变面板

1. **打开渐变工具**: 
   - 选中盾形
   - 点击渐变工具或 按 G

2. **设置类型**:
   - Linear Gradient (线性渐变)

3. **设置角度**:
   - 180° (从上到下垂直)

4. **添加色标**:
   - 拖动渐变条添加色标
   - 或点击 "+" 按钮

5. **色标位置和颜色**:
   ```
   色标 1: 位置 0%   → 颜色 #005EB8
   色标 2: 位置 35%  → 颜色 #0077B6
   色标 3: 位置 65%  → 颜色 #00A896
   色标 4: 位置 100% → 颜色 #10B981
   ```

6. **平滑度**: 设置为最高（Smoothness: High）

## 🔧 常见问题解决

### 问题 1: 渐变看起来有色带
**解决**:
- 增加色标数量（4个色标比2个更平滑）
- 确保平滑度设置为 High
- 导出时选择高质量设置

---

### 问题 2: 32px Favicon 太模糊
**解决**:
- 创建简化版本 (A3)
- 移除渐变，使用单色 `#0077B6`
- 移除所有填充，仅保留线条轮廓
- 增加线宽到 3-4px (相对于32px画布)

**操作**:
1. 复制主设计图层
2. 删除渐变填充 → 改为单色
3. 简化心形细节
4. 导出为 32×32px

---

### 问题 3: 形状不对称
**解决**:
- 使用网格和吸附功能
- 绘制一半后，使用镜像工具复制另一半
- 确保中心对齐线精确在 512px

---

### 问题 4: 曲线不平滑
**解决**:
- 使用更少的锚点（3-5个足够）
- 调整贝塞尔曲线的控制手柄
- 确保 Line Cap 设置为 Round

## 💡 高效技巧

### 技巧 1: 使用图层
```
图层结构:
├── 背景层 (锁定)
├── 盾形
├── 心形
├── 曲线
└── 装饰元素 (数据点)
```

### 技巧 2: 保存多个版本
```
文件 > 另存为
logo-a1-draft-v1.nanana
logo-a1-draft-v2.nanana
logo-a1-final.nanana
```

### 技巧 3: 使用快捷键
- `P`: 钢笔工具
- `V`: 选择工具
- `G`: 渐变工具
- `Ctrl+D`: 复制
- `Ctrl+Z`: 撤销
