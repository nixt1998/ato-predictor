## 🔧 常见问题修正

### 问题 1: 生成了文字
**解决**: 在提示词末尾添加
```
, no text, no letters, no words, icon only
```

### 问题 2: 颜色不对
**解决**: 明确指定
```
exact colors: #005EB8 blue and #10B981 green gradient
```

### 问题 3: 太复杂/花哨
**解决**: 强调
```
minimalist, simple, flat design, clean lines, vector style
```

### 问题 4: 有阴影或3D效果
**解决**: 添加
```
flat design, no shadows, no 3D effects, 2D vector illustration
```
