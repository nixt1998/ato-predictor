## 💡 设计建议

### 颜色使用技巧

**推荐做法** ✅:
- 盾形/圆形使用完整渐变（4色标）
- 心形使用单色或简单双色渐变
- 曲线/箭头使用亮绿色 `#10B981` 作为视觉焦点

**避免做法** ❌:
- 不要使用红色（与心脏毒性警示冲突）
- 不要使用黑色或纯灰（缺乏生命力）
- 不要过度渐变（超过4个色标会显杂乱）

---

### 元素组合技巧

**推荐做法** ✅:
- 主体元素（盾/圆）占画布 70-80%
- 心形占主体的 40-45%
- 曲线/箭头不超过心形高度的 60%
- 保持元素间适当留白

**避免做法** ❌:
- 不要让元素贴边（至少留 10% 边距）
- 不要让心形过小（<35% 会看不清）
- 不要让曲线过于复杂（影响缩小后识别）
