# ATO CardiTox Logo 草图方案

**设计日期**: 2026-08-18  
**方案数量**: 3 个主方案 × 3 个变体 = 9 个草图

---

## 方案 A: "守护之盾" (Guardian Shield)

### 核心概念
**一句话**: 盾形保护心脏，曲线预示未来

### 视觉描述（供手绘参考）

#### A1 - 实心盾牌 + 线条心形（推荐）
```
     /\
    /  \
   /    \
  |  ♡  |  ← 线条勾勒的几何心形（非爱心形状）
  |  ~  |  ← 从心脏底部延伸的预测曲线
  |  ~~ |
   \  /
    \/
```

**详细说明**:
1. **盾形外轮**: 
   - 标准盾牌形状，顶部尖角向上
   - 宽高比 约 4:5
   - 填充: 蓝绿渐变 #005EB8(顶) → #10B981(底)

2. **心形中心**:
   - 由两个圆弧（上）+ 一个三角（下）组成
   - 仅线条勾勒，无填充
   - 线宽: 3-4px (根据总尺寸调整)
   - 颜色: 白色或 #FFFFFF

3. **预测曲线**:
   - 起点: 心形底部尖端
   - 路径: 平滑上升曲线，向右上方延伸
   - 风格: 类似心电图的单条波形
   - 颜色: #10B981 (亮绿)
   - 可选: 添加 2-3 个数据点圆圈

**尺寸比例**:
- 盾形: 100% 画布
- 心形: 占盾形高度的 40-45%
- 曲线长度: 心形高度的 60%

---

#### A2 - 线条盾牌 + 实心心形
```
     /\
    /  \
   /    \
  | ███  |  ← 实心填充的几何心形
  |  ~~ |
   \  /
    \/
```

**差异点**:
- 盾形: 仅保留 4-5px 线条轮廓，无填充
- 心形: 实心填充渐变 #005EB8 → #0077B6
- 曲线: 从心形内部延伸出来
- 整体: 更轻盈，适合小尺寸

---

#### A3 - 全线条风格（小尺寸优化）
```
     /\
    /  \
   /    \
  |  ♡  |  ← 所有元素均为线条
  |  ~  |
   \  /
    \/
```

**特点**:
- 所有元素统一线宽 (3px)
- 无任何填充或渐变
- 使用单一颜色 #005EB8 或 #0077B6
- **最适合**: 16x16, 32x32 favicon
- **优势**: 清晰锐利，不糊

## 方案 B: "数据守护" (Data Guardian)

### 核心概念
**一句话**: 心脏被数据流环绕，科技感最强

### 视觉描述

#### B1 - 完整环绕曲线（推荐）
```
     ___....___
   .'           '.
  /   ___   ___   \
 |   /   \ /   \   |  ← 几何心形（两个三角形拼接）
 |   \___/ \___/   |
  \      ~~~      /  ← 环绕的波形曲线
   '.___....___.'
```

**详细说明**:
1. **圆形保护圈**:
   - 正圆或略扁的椭圆
   - 线条: 2-3px，渐变 #005EB8 → #00A896
   - 可选: 虚线样式（间隔均匀）

2. **几何心形**:
   - 由两个等边三角形顶对顶组成（形成菱形）
   - 或: 圆形+倒三角形组合
   - 填充: 实心 #0077B6
   - 位置: 圆心位置

3. **环绕曲线**:
   - 风格: 心电图 PQRST 波形简化版
   - 路径: 沿着圆形保护圈的内侧或外侧
   - 颜色: #10B981
   - 可包含 3-5 个波峰波谷

**视觉动线**:
- 曲线从左侧起始 → 穿过顶部 → 右侧下降 → 底部回升
- 象征持续监测的循环过程

---

#### B2 - 部分曲线（留白更多）
```
     ___....___
   .'           '.
  /      ♦       \  ← 菱形心脏
 |                |
  \      ~~      /  ← 曲线仅覆盖底部 1/3
   '.___....___.'
```

**差异点**:
- 曲线仅出现在底部 90-180° 区域
- 顶部留白增加透气感
- 心形可改为菱形或六边形
- 更极简，适合中小尺寸

---

#### B3 - 心电图风格波形
```
       ___
     _|   |_
   _|       |_
  |    ♥     |  ← 抽象心形
  |_   ∧    _|  ← 明显的 QRS 波群
    |_| |_|
```

**特点**:
- 圆形改为横向椭圆（16:10）
- 曲线模拟真实心电图的 PQRST 波
- 背景可添加网格线（浅色）
- **适合**: 医疗专业场景
- **风险**: 可能过于具象，识别度降低

## 方案 C: "预测之眼" (Predictive Eye)

### 核心概念
**一句话**: 盾+心+向上趋势的垂直构图，强调"预见未来"

### 视觉描述

#### C1 - 完整盾形 + 实心心脏（推荐）
```
     /\
    /  \
   / ↑  \    ← 向上的箭头/曲线穿过心形
  | ███  |   ← 实心心脏作为视觉中心
  |  |   |
   \ | /
    \|/
     ▽
```

**详细说明**:
1. **盾形基底**:
   - 与方案A相同的盾牌轮廓
   - 填充: 完整渐变 #005EB8 → #10B981
   - 或: 50% 透明度渐变

2. **心形核心**:
   - 位置: 盾形上半部（约 1/3 处）
   - 风格: 几何化心形，非爱心
   - 填充: 实心深蓝 #005EB8
   - 或: 负空间（镂空）

3. **向上趋势线**:
   - 起点: 盾形底部中心
   - 路径: 穿过心形中心，延伸至顶部
   - 风格: 粗箭头或平滑曲线
   - 颜色: 亮绿 #10B981 或白色
   - 可选: 箭头末端添加上升趋势的折线

**象征意义**:
- 箭头/曲线 = 风险预测轨迹
- 穿过心脏 = 聚焦心脏健康
- 向上 = 积极预后、风险下降

---

#### C2 - 半透明盾形 + 线条心脏
```
     /\
    ╱  ╲
   ╱ ♡  ╲   ← 线条心形
  ╱  ↑   ╲  ← 透明盾形 + 明显箭头
 ╱   |    ╲
╱    |     ╲
```

**差异点**:
- 盾形: 30-40% 透明度，渐变更柔和
- 心形: 白色线条勾勒
- 箭头: 实心填充，视觉重量最大
- 整体: 轻盈感，科技感更强

---

#### C3 - 极简版（心+箭头+盾轮廓）
```
     ∧
    / \
   | ♡ |    ← 仅保留最小元素
   | ↑ |
    \_/
```

**特点**:
- 移除所有填充
- 仅保留: 盾形轮廓 + 心形轮廓 + 箭头
- 统一线宽
- **适合**: 极小尺寸（16px favicon）
- **优势**: 高对比度，清晰锐利

## 📐 手绘指南

### 建议工具
- **纸笔草图**: 先用铅笔在方格纸上绘制比例
- **Nano Banana Pro**: 矢量绘图，支持精确控制
- **参考网格**: 建议使用 10x10 或 12x12 网格辅助对齐

### 绘制顺序
1. **定位基准线**: 确定中心点和对称轴
2. **绘制主体**: 盾形/圆形外轮廓
3. **添加核心**: 心形元素
4. **叠加细节**: 曲线/箭头/数据点
5. **颜色填充**: 应用渐变色
6. **小尺寸测试**: 缩小至 32px 检查清晰度

### 色彩代码参考
```css
/* 主要色彩 */
--medical-blue: #005EB8;
--tech-blue: #0077B6;
--teal: #00A896;
--life-green: #10B981;
--protect-green: #059669;

/* 渐变示例 (CSS) */
background: linear-gradient(180deg, #005EB8 0%, #10B981 100%);
background: linear-gradient(135deg, #005EB8 0%, #00A896 50%, #10B981 100%);
```
