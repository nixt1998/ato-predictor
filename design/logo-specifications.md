### 元素比例（基于 1024px 画布）

#### 方案 A: 守护之盾

```
画布: 1024×1024px

盾形外轮廓:
- 宽度: 700px (画布的 68%)
- 高度: 850px (画布的 83%)
- 位置: 水平居中，垂直居中偏上
- 顶部尖角: 距画布顶 87px
- 底部尖角: 距画布底 87px

心形:
- 宽度: 280px (盾形宽度的 40%)
- 高度: 250px
- 位置: 盾形中心，垂直偏上 50px
- 样式: 线条宽度 8px (A1) 或 实心填充 (A2)

预测曲线:
- 起点: 心形底部尖端
- 长度: 约 150px
- 线宽: 6px
- 数据点圆圈直径: 12px (可选)
```

#### 方案 B: 数据守护

```
画布: 1024×1024px

圆形保护圈:
- 直径: 800px (画布的 78%)
- 位置: 完全居中 (112px 边距)
- 线宽: 5px

几何心形:
- 宽度: 320px
- 高度: 280px
- 位置: 圆心
- 形状: 菱形或两三角形组合

环绕曲线:
- 路径: 距圆形边缘内侧 40px
- 线宽: 4px
- 波峰波谷数量: 3-5 个
- 幅度: ±30px
```

#### 方案 C: 预测之眼

```
画布: 1024×1024px

盾形基底:
- 与方案 A 相同 (700×850px)

心形核心:
- 宽度: 300px
- 高度: 270px
- 位置: 盾形顶部下方 250px

向上箭头/趋势线:
- 起点: 盾形底部中心
- 终点: 盾形顶部尖角
- 线宽: 10px (粗箭头) 或 6px (细曲线)
```

## ✅ Nano Banana Pro 工作流程

### 第 1 步: 新建项目
```
文件 > 新建
- 画布: 1024×1024px
- 色彩模式: RGB
- 背景: 透明
- 单位: Pixels
```

### 第 2 步: 设置网格（可选）
```
视图 > 显示网格
- 网格大小: 64px (16×16 网格)
- 细分: 8 (每格 8px 小格)
- 吸附到网格: 开启
```

### 第 3 步: 创建色板
```
色板管理器:
1. 添加 #005EB8 (命名: Medical Blue)
2. 添加 #0077B6 (命名: Tech Blue)
3. 添加 #00A896 (命名: Teal)
4. 添加 #10B981 (命名: Life Green)
5. 添加 #FFFFFF (命名: White)
```

### 第 4 步: 绘制主形状
```
工具: 钢笔工具 / 形状工具
1. 绘制盾形外轮廓（参考上方 SVG 路径）
2. 应用渐变填充（渐变 1）
3. 绘制心形（中心对齐）
4. 添加曲线/箭头
```

###第 5 步: 小尺寸优化
```
复制主设计图层
1. 缩放到 32×32px
2. 检查清晰度
3. 如果模糊:
   - 移除渐变 → 改用单色
   - 减少元素细节
   - 增加线宽（相对）
```

### 第 6 步: 批量导出
```
文件 > 导出 > 批量导出
- 选择所有需要的尺寸
- 格式: PNG (透明背景)
- 压缩: 最佳质量
- 文件命名: 按规范命名
```

## 📞 问题排查

### 问题 1: 小尺寸模糊
**解决方案**:
- 使用 A3 或 C3 全线条版本
- 增加线宽到 3-4px
- 移除渐变，使用单色

### 问题 2: 渐变不平滑
**解决方案**:
- 增加中间色标（4个色标比2个更平滑）
- 使用 "Perceptual" 色彩混合模式
- 导出时选择高质量设置

### 问题 3: 文件过大
**解决方案**:
- SVG: 简化路径，移除不必要的点
- PNG: 使用 TinyPNG 或 ImageOptim 压缩
- 目标: 网站用 PNG <50KB, SVG <30KB
